"Harmful Helpfulness": Claude Sonnet 4.5.

An end-to-end NLP and pipeline diagnosing public discourse surrounding Claude's LCR-triggered clinical interventions. We prove when LLMs over-diagnose user inputs, it directly triggers severe gaslighting trauma.

01 / Subject Clustering

Isolating the Gaslighting Phenomenon.

Using BERTopic, we fed highly unstructured r/ClaudeAI Reddit discourse through a dynamic topic clustering pipeline. Rather than forcing user complaints into arbitrary "negative sentiment" bins, the algorithm organically grouped complaints surrounding unsolicited diagnoses—a phenomenon where Claude tags regular creative inputs as "manic" or "distressed" and proceeds to lock the user out with psychiatric advice. 

# Transforming raw discourse into dense vector states
topic_model = BERTopic(language="english", calculate_probabilities=True)
topics, probs = topic_model.fit_transform(documents)

# Identifying the exact cluster mapped to "Harmful Helpfulness"
harmful_cluster = topic_model.get_topic_info().query("Name.str.contains('diagnose|clinical|harm')")
